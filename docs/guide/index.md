# Guide

Practical use of tax, organised by capability:

- [**Arithmetic**](arithmetic.md) — `+`, `-`, `*`, `/`, scalars, the
  `.eval()` driver, lifetime caveats.
- [**Math functions**](math-functions.md) — `sin`, `cos`, `exp`, `log`,
  `sqrt`, the rest of the catalogue.
- [**Multivariate**](multivariate.md) — `TEn<N, M>::variables`, the
  multi-index layout, partial derivatives.
- [**Derivatives & evaluation**](derivatives.md) — `coeff`,
  `derivative`, `eval`, norms, and the three index-passing forms.

If you haven't yet, skim [**Concepts**](../concepts/index.md) first —
the rest of the guide assumes the streaming / static-vs-dynamic
vocabulary.
